# only 발전 방향 — portfolioweb 비교 및 기능 제안

> 검토일: 2026-09-13
> 비교 대상: `moneyProject/only`, `moneyProject/portfolioweb`
> README·화면·API·데이터 모델·발송 코드를 확인한 결과입니다. 실제 외부 서비스 연결 및 발송 성공 여부는 검증하지 않았습니다.

## 1. 기본 방향

`only`를 가족 자산 관리의 중심으로 발전시키고, `portfolioweb`의 투자 분석·알림 기능을 필요한 순서대로 가져옵니다.

- `only`의 강점: 가족별 로그인·조회 권한, 가계부, 주식·코인·부동산·부채 통합, 일정, 자산 이력.
- `portfolioweb`의 강점: 관심종목, 손절 알림, 시장 브리핑, 심화 종목 분석, 투자 메모.
- 텔레그램 목표가 알림과 뉴스·OpenDART 분석은 `only`에도 이미 있습니다. 신규 도입보다는 확장 대상으로 봅니다.

## 4. 텔레그램 기능 상세

### 현재 구현

- 시세 갱신 시 현재가가 목표가 이상이면 알림을 보냅니다.
- 성공 기록으로 중복을 막으며, 목표가를 변경하면 다시 알림을 받을 수 있습니다.
- 연결 테스트 API와 발송 결과 저장 기능이 있습니다.
- 발송 대상은 설정된 채팅방 하나이며, 본문은 4,000자로 잘립니다.
- 가격 조건은 시세 갱신 시점에 판정합니다. 장중 알림을 강화하려면 갱신 주기도 함께 조정해야 합니다.
- portfolio에는 나스닥·반도체 지수와 뉴스를 모아 전송하는 스크립트가 있습니다. 정기 실행 설정 여부는 별도로 확인해야 합니다.

### 첫 버전 후보

- [ ] 예약 발송: 아침 시장 브리핑과 저녁 자산 요약을 각각 켜고 끄기.
- [ ] 조건 알림: 목표가 이상·손절가 이하·관심 매수가 이하 도달.
- [ ] 수동 발송: 종목 분석과 포트폴리오 요약 보내기.
- [ ] 수신 범위: 관리자는 전체, 가족은 본인 자산, 가족 단체방은 공통 요약.
- [ ] 발송 관리: 미리보기, 중복 방지, 실패 재시도, 긴 보고서 분할, 상세 화면 링크.
