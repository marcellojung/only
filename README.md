# 온리 — 우리 둘의 자산

부부 두 사람만 사용하는 비공개 웹앱입니다. 주식/ETF, 가계부, 암호화폐, 부동산, 가족별 자산, Google Calendar 일정을 한 화면에서 관리합니다.

## 로컬 개발

Node.js 22 이상과 pnpm을 설치한 뒤 실행합니다.

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 비공개 웹앱 운영

Vercel, Render, Railway 등 Next.js를 지원하는 웹 호스팅에 이 프로젝트를 연결합니다. 호스팅 환경 변수에 다음 값을 설정합니다.

- `APP_ACCESS_KEY`: 두 사람만 아는 충분히 긴 접근 키
- `DATABASE_URL`: 호스팅 또는 별도 서비스에서 만든 PostgreSQL 연결 주소
- Google Calendar 관련 환경 변수 3개

`DATABASE_URL`이 없으면 화면 확인용 데모 데이터로 동작하고, 설정하면 두 아이폰이 같은 비공개 DB 데이터를 공유합니다. 웹에서는 반드시 HTTPS를 사용하고, 검색엔진 노출은 기본적으로 차단됩니다.

아이폰 Safari에서 배포 주소를 연 뒤 **공유 → 홈 화면에 추가 → 웹 앱으로 열기**를 선택하면 일반 앱처럼 실행됩니다.

## Google Calendar 연결

1. Google Cloud Console에서 프로젝트와 서비스 계정을 만들고 Calendar API를 활성화합니다.
2. 부부가 사용할 공유 캘린더 설정에서 서비스 계정 이메일에 **일정 변경 권한**을 부여합니다.
3. 호스팅 환경 변수에 `GOOGLE_CALENDAR_ID`, `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`를 입력합니다.
4. 웹앱을 다시 배포합니다.

설정 전에도 화면과 일정 추가 흐름을 시험할 수 있으며, 연결 후 새 일정은 공유 Google Calendar에 기록됩니다.

## 카드 내역 가져오기

가계부 탭에서 `.xlsx`, `.xls`, `.csv` 파일을 선택합니다. `이용일/결제일/날짜`, `가맹점명/이용가맹점/상호`, `이용금액/결제금액/금액` 열을 우선 인식하고 식비, 교통, 구독, 건강, 생활 항목으로 자동 분류합니다.

## 주식/ETF 가져오기

주식/ETF 탭에서 증권사 `.xlsx`, `.xls`, `.csv` 파일을 선택합니다. 다음 열 이름을 자동으로 인식합니다.

- 종목: `종목명`, `상품명`, `종목`, `보유종목`
- 코드: `종목코드`, `티커`, `코드`, `Symbol`
- 수량: `보유수량`, `잔고수량`, `수량`, `Quantity`
- 단가: `평균단가`, `매입단가`, `평균매입가`, `현재가`, `평가단가`
- 기타: `평가금액`, `통화`, `소유자`, `명의`

현재가가 없고 평가금액이 있으면 `평가금액 ÷ 수량`으로 현재가를 계산합니다. 영문 티커는 기본 USD, 숫자 종목코드는 기본 KRW로 인식합니다.
